The user will first enter registration details, which enter firstname,lastname,username,password and cellphone number.
Username should not contain more than 5 characters and should contain '_'.
Password should contain one Capital letter,number and special character as it should be 8 or more characters long.
Cellphone number should start with "+27".
After that you will be successfully registered.
